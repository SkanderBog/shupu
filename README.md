# 数谱 | 简谱工作台

一款自由的简谱制谱、编辑、排版、试听工具。着重处理多声部乐谱制作，谱面万物皆元素，元素可自由移动，属性可自由设定。

## 下载与入门

从 [发行版](https://github.com/zgqsine/shupu/releases) 下载 **数谱-简谱工作台-1.0.html**，用 Chrome 或 Edge 打开。单文件包含程序和示例谱，双击即可离线使用。

- 「文件 → 打开样谱」打开示例谱《四季流转》。可以新建乐谱或导入 MusicXML。
- 按 **N** 切换常规模式与音符输入模式，输入 **1–7** 或 **0**。选中一个音符按 **L** 填词。
- 「保存工程」保存可继续编辑的 `.shupu` 文件。「导出…」可选 PDF、PNG、SVG 或 MusicXML。
- 「帮助」里有入门使用介绍、完整功能手册和快捷键设置。

遇到问题或有功能建议，欢迎 [提交 Issue](https://github.com/zgqsine/shupu/issues/new/choose)。请附上版本、运行环境和复现步骤。能公开分享的最小示例谱也很有帮助。

## 从源码运行

使用 Node.js 和 npm。

```sh
npm ci
npm test
```

`npm run build` 生成便携 HTML。`npm run preview` 在本机启动预览服务。`npm start` 构建并启动 Electron 桌面版。

## 作者的话

在我参加合唱团排练时，经常能感觉到在中文环境下简谱相对于五线谱的需求量与制谱软件的极大错位：很多人都更擅长阅读简谱——甚至有些人只会阅读简谱——但是整个互联网上目前却很难找到一个功能齐全、排版美观、支持导入导出MusicXML、免费可用的简谱制谱软件。相比之下，五线谱则有大量的专业级制谱软件：MuseScore（尤其是它开源免费）、Sibelius、Dorico……

在切身体会到这种需求之后，我庆幸自己拥有MuseScore多年制谱经验让我可以相对完备地设计这款简谱制谱软件的功能，也庆幸如今的AI工具已经足够发达，可以让我凭借上百轮对话、每轮成百上千字的设计提示词交互，就完成这款产品的开发。现在呈现出来的这版数谱里，既有我的精细功能逻辑设计，也有GPT的准确理解与执行。

1.0版本只是起点，它可能会有bug，可能会有用起来不顺手的设计，也必定还不能覆盖所有简谱使用者的需求——数谱的发展完善之路上需要你。遇到问题、想修改功能设计、想加新功能请提Issue，也非常欢迎直接提PR参与开发。如果你觉得数谱是一个好用的简谱制谱软件，帮你节省了简谱排版的时间，欢迎点个Star，把它介绍给身边的音乐爱好者朋友们。

——赵冠乔 写于2026年11月
